# Decisions pending the owner

One list of every open decision across all tickets, so the owner answers once (CC-311, ADR-072, process in
[PROCESS.md](PROCESS.md)). The coordinator keeps it: it adds each ticket's Open decisions rows here when the ticket
reaches Spec review, sends the list to the owner as one batch, and on an answer writes it into the ticket and its
ADR and removes the row. A row with no answer takes its recommended default on its default day.
