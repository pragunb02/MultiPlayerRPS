A rematch now gives the first move (X in Tic Tac Toe, White in chess) to the player who did not start the game
before, game after game, also against computer characters and after a server restart. Before, the starter was drawn
from each game's seed, so the same player could start every game (BUG-23). Game 1 of a room is still drawn from the
seed. The engines take an optional starter, a rematch's starter is recorded beside its seed in the room and the
match, and replays use it. Rock Paper Scissors and pass and play are unchanged.
