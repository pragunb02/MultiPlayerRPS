A player can no longer have more than 3 challenges open by making them in the same millisecond. The limit used to
be decided by sorting the sender's challenges by time after the new one was stored. Challenges from the same
millisecond were then ordered only by their random ids, so a fourth could count as one of the first three. Each
open challenge now holds one of its sender's three places, and a unique index lets only one challenge hold each
place, so the limit holds in one write. A place is let go once its challenge can never be open again: expired,
declined, withdrawn, or taken with its room made. A new integration test on MongoDB made 4 open challenges before
the fix, and makes 3 now.
