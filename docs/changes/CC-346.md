they are the six CC-172 layouts marked as expected to fail, which Playwright marks ✘ and counts as passed, and a
comment now says so. "Sign out other devices" could show the player signed out: a request the profile page had on
its way with the old session id was read after the server dropped it, so "who am I?" answered "signed out" (or a
read answered 401). The web app now sends a password change or "sign out other devices" once the requests on
their way are answered (or after 3 s at most), and holds new ones until it is. The renewal is given up after 90 s
and nothing waits behind it longer, while other requests still wait as long as a sleeping server takes to wake. Under load the browser test failed 4 times in 400 before
and 0 in 320 after. In a room whose game had just started, Leave room showed under "Loading the board…" and moved
down when the board's download arrived, so a press could land on the board, and CI's Firefox forfeit test waited
for a dialog that never opened. The board's place is now kept while it downloads, as tall as the smallest board of
that game at that width, so Leave room can always be pressed, keeps its focus and stays where it is.
