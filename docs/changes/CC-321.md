The effects and animation stack is decided by tier, from measurements (ADR-075, design/EFFECTS-STACK.md): CSS and the motion tokens for simple effects, Motion through named presets for counters, progress and reward reveals, and our own 0.75 kB canvas particle module for celebrations and seasonal themes, all loaded through one effect registry that CC-312 flags switch on and off. 19 libraries and 5 platform features were built with `npm run build:web` on a throwaway branch, run under the production CSP in Chromium, Firefox and WebKit, and timed at 4× and 6× CPU throttling on a phone-sized screen. GSAP, AutoAnimate, React Spring, Lottie, dotLottie, Rive, tsParticles, PixiJS, three.js, React Three Fiber, OGL, Tailwind, Radix, React Aria and shadcn/ui are rejected, with reasons: several fail under our CSP (WebAssembly, `eval`, injected `<style>`), and the 3D ones are larger than the whole first route. No dependency and no CSP change. Measured along the way: the first route is 192.2 kB gzip, not about 153 kB.
