Two test files no longer fail on a loaded laptop. `server.integration.test.js` made a new database for every
test, so each server start created about 110 collections and indexes. mongod syncs each one to disk, which took
1.4 s on a quiet Mac and over 5 s under load. At the end mongod synced about 2,700 files as it stopped, which ran
past the 10 s hook limit. Its tests now share one database, emptied before each test. The file runs in 7 s instead
of 38 s, and mongod stops in under 2 s. Its CC-095 test waits for each game's progress push instead of sleeping.
In `challengeRoutes.test.js`, two challenges made in the same millisecond had no order but their random ids. The
tests that depend on order now use a clock that moves on at each reading. Under load: 24 of 24 heavy runs passed,
where 16 of 16 failed before, and 40 of 40 challenge runs passed, where 3 of 31 failed before. No timeout was
raised and nothing is retried.
