Challenges with their own link: the lobby's Make a challenge link opens `/challenge/:id`, a random 100-bit id
that lasts 24 hours and survives restarts (a new `challenges` collection with a TTL index). Whoever opens it plays
as a guest or logs in and takes it, and a room is made with both players seated. The challenger hears it on any
page. Expired, taken back, taken and unknown links get an honest page. A blocked pair sees only an expired
challenge, the creator's name shows only for an adult account, at most 3 are open per sender and one per 10
minutes to the same person, and no answer carries a player id. The API takes a profile handle for CC-052's
friends, and names nobody until then.
