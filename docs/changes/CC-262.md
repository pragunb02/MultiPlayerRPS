The profile's Account section now lists the account's signed-in devices beside "Sign out other devices": a coarse
browser and system such as "Chrome on Android", the sign-in day and the last-seen day (India days), "This device" on
the one in use, and Sign out on each other one, which deletes only that session at once and cuts its sockets. Each
session gets a random device id, the only name the browser gets for it: no session id is ever sent, and another
account's device id answers 404. The board's "rough place" was dropped for privacy, so no IP address or place is
stored or shown (ADR-081).
