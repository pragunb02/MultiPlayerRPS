A friend request sent while its recipient's browser is between pages or reconnecting now still shows the "wants to be your friend" toast. The toast came only from the request's push, which reaches only the tabs connected at that moment. Now the server sends a connecting tab each request that rang in the last 15 minutes, still waits and no page of that browser answered, and nothing it chose not to announce (a minor's quiet hours, a block). Pages answer each ring once its toast is up, and which rings a browser heard is kept beside its session in the database, so a reload or a deploy shows no second toast. Room invites and challenge popups already caught up on connect and are unchanged.
