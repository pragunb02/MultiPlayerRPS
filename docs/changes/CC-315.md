New ticket, shaped and at Spec review (owner, 2026-10-20: many features are adding text and pop-ups): an interruption budget and one notification centre. One client-side arbiter, extending the CC-208 categories and the CC-163 hold, decides which toast, banner, ask or app-opened dialog shows, in what order and how many: per screen, per game and per visit, with a quiet period during play that only the opponent's request and a lost connection break, a new `ask` category capped at one per visit, and anonymous counts for the console. CC-099 depends on it and becomes its result surface. Six open decisions in `docs/DECISIONS-PENDING.md`, defaults on 2026-10-22.
