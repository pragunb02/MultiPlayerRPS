Password hashes meet OWASP's minimum again (SEC-23): new hashes use scrypt N=2^15, r=8, p=3, still 32 MiB per
hash on Render's 512 MB, about 127 ms on the owner's laptop against 40 ms before. Older hashes keep their own
parameters and still verify, and are made again at the next successful login. That save is best effort now: a
failure no longer fails the login and is logged as a warning. The dummy check for unknown emails uses the new
parameters, so timing still says nothing about who has an account.
