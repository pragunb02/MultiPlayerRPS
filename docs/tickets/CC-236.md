## Why

The browser job takes about 16 minutes (CI run 39055903179: 322 tests, 2 workers, 15.9 min). `match-shell.spec.js` is about 1272 of 1819 test-seconds: each "every press answers within 100 ms" state waits through real rematch and result timings (30 to 36 s each). The chess flag test waits a real minute twice. Every pull request waits on this job, so it slows all work.

## Scope

- In: short timers for browser tests only (the server already accepts lifetimes overrides for tests, `roomLifetimes.js`), or Playwright's clock; sharding across 3 CI machines with a merged report; worker count measured; a per-file time summary on every run.
- Out: removing tests or weakening what they check; production timings.

## Acceptance criteria

- [ ] The browser job finishes in under 6 minutes on CI, measured on three runs
- [ ] No test checks less than before (same assertions)
- [ ] Production starts with the standard timings, proved by a test
- [ ] Tests cover the change
- [ ] `npm run lint`, `npm run format:check`, `npm test` pass
- [ ] Docs updated (BACKLOG status, KNOWN_ISSUES, PROGRESS)
