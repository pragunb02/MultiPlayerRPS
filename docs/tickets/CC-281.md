## Research (written before any code)

1. **Our code today.** `tokens.css` has five durations (80, 120, 200, 360, 1200 ms) and three easings (out,
   in-out, spring), all zero under reduced motion. The CSS modules hold 37 `@keyframes`; `spin` and `slide-in` are
   each defined twice, and raw timings remain (Bit's 400 ms glow and 130 ms steps, the flame's 900 ms flicker,
   staggered delays in `effects.module.css`, the waking-up timings). Nothing checks for raw timings. There is no exit
   easing and no exit animation: toasts and dialogs vanish (CC-092's open part).
2. **Others.** IBM Carbon motion (carbondesignsystem.com/elements/motion/overview, read 2026-10-19): six duration
   tokens (70 to 700 ms) and "productive" and "expressive" easing families, each with standard, entrance and exit
   curves. Material Design 3 (general knowledge, high confidence): named durations and emphasized and standard
   easings with separate entrance and exit curves. MDN `@starting-style` and `transition-behavior: allow-discrete`
   (Baseline 2024, August 2024): CSS entry and exit transitions for dialogs, popovers and `display: none`, with no
   script.
3. **Best for ClassiCade.** Add an exit easing and a stagger step token; write five named recipes (enter, exit,
   pop, stagger, celebrate) as shared keyframes in one module; move every keyframe onto tokens; add exit
   transitions to toasts and the shell's dialog with `@starting-style` (CSS only, ADR-049 point 3); and add a check
   (the CC-125 CSS check or a unit test over the CSS modules) that fails on a raw `ms` or `s` timing outside
   `tokens.css`, with a short documented list of exceptions. No library.

## Why

Timings drift one module at a time, reduced motion depends on every module using tokens, and CC-153's new motion
needs a shared vocabulary.

## Scope

- In: tokens, recipes, migration of every CSS module, toast and dialog exits, card flip recipe, the check.
- Out: Motion on new pages (ADR-016), page transitions (CC-153d).

## Acceptance criteria

- [ ] No raw timing in any CSS module outside the documented exceptions (check fails otherwise).
- [ ] No duplicate keyframe names.
- [ ] Toasts and the confirm dialog fade out in 200 ms or less, and not at all under reduced motion.
- [ ] Tests cover the change; `npm run lint`, `npm run format:check`, `npm test` pass.
- [ ] Docs updated (BACKLOG, PROGRESS, ADR-012 note).
