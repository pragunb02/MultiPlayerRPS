## Why

The vision's first 60 seconds (PRODUCT_VISION.md §4.1): one tap on the main button and the board appears against a
labelled character. Inviting a friend needs a second person, so it cannot be the main action for a visitor alone.

## Scope

- In: each game's page leads with "Play Rocky", "Play Pip" or "Play Queen Vee" (`components/PlayComputer`): the
  character with a Computer badge and its tagline, a one-tap level pick (Easy and Hard for Rocky, Easy, Medium and
  Unbeatable for Pip, Beginner, Club player and Strong for Queen Vee), a line saying how it plays at that level, and
  the note that games against the computer count for quests and up to 100 XP a day and never on leaderboards.
- In: the button calls the new socket event `room:play-computer` `{ gameId, level, options }` and opens the room with
  the game already on. A visitor without a session becomes a guest first, as Create room does.
- In: "Play a friend" with the game's options and Create room stays, now the secondary button, and joining by code is
  unchanged. Every control has a `data-cc-control` (`lobby.computer_level`, `lobby.play_computer`) and answers within
  100 ms: pressing the level already picked brings its line in again.
- Out: rating seeding from the level pick (CC-042, ADR-027), the parallel search for a person (CC-051), lobby
  options for games against the computer (they use each game's defaults: best of 3, Blitz 5 min).

## Acceptance criteria

- [x] The main button on each game page plays the game's character, one tap for the level.
- [x] The game starts at once, with the character seated.
- [x] Inviting a friend stays as the second path.
- [x] Time to first move from the lobby under 2 seconds locally: measured and asserted.
- [x] Every new control answers within 100 ms (`e2e/match-shell.spec.js`, state "computer lobby").

## Plan / notes

Measured with `e2e/computer.spec.js` ("Play Rocky…"), from the press on Play Rocky to the room page showing the
player's turn, on this machine with the production build and the production pause before computer moves:
487, 522 and 568 ms on desktop and 492, 570 and 583 ms on mobile (Pixel 7 emulation), all with the machine loaded by
other test runs. Rock Paper Scissors lets the person throw at once. In Tic-Tac-Toe and chess the character may
start, which adds its pause of 400 to 900 ms, still inside 2 seconds.
