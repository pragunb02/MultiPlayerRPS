## Problem

Main's CI on 7ece1ed (#161) failed with "ReferenceError: window is not defined" from `TelemetryStub.jsx:73`,
raised while `FriendsPage.test.jsx` ran. Root cause: the stub's idle download of the telemetry host had no cleanup.
After the app unmounted (a test ending, or the page closing), a failed download still scheduled its retry and touched
`window`, and a late success still set state on an unmounted component.

## Fix

The effect remembers when the stub is gone and then does nothing more: no download, no retry, no state. It also keeps
the window it started with. Research: React's effect cleanup is the documented place to stop async work an effect
started (react.dev, "Synchronizing with Effects", fetching data).

## Acceptance criteria

- **AC-1** Given the stub unmounted, when its idle moment or a failed download comes after, then nothing more is
  downloaded and nothing touches the page.
