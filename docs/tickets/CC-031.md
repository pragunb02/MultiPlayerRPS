## Scope

- `.github/dependabot.yml`: every Monday 06:00 IST.
  - **npm** (one lockfile for all workspaces): patch + minor updates grouped into two PRs — dev tools, runtime
    libraries — so runtime changes are reviewed on their own; each **major** release in its own PR; at most 5 open.
  - **GitHub Actions**: one grouped PR.
- Dependabot proposes stable releases only (our policy, ENGINEERING.md §5). `npm audit --audit-level=high` already
  gates every PR (CC-027).
- Starting point: every direct dependency is on its latest stable version (`npm outdated` empty); audit 0.

## Owner settings (GitHub → Settings → Code security)

- Turn on **Dependabot alerts** and **Dependabot security updates** — security fixes then arrive as PRs immediately,
  not only on Mondays.
