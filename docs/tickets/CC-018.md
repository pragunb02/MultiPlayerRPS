## Why

First real game on the engine contract. The legacy RPS sent a player's choice to the opponent before the result
(SEC-09, cheatable in DevTools), mis-spelled "Scissors" (BUG-01) and kept only the last round's winner (BUG-02).

## Scope

- In: `rpsEngine` (best of 1/3/5/7, default 3; simultaneous secret choices; drawn rounds replayed; round history and
  score); shared `RPS_CHOICES`, `RPS_BEST_OF`; registered in `ENGINES` (now playable through rooms/sockets).
- Out: web UI (CC-024), RPS bots (CC-038), match persistence/XP (CC-016/017).

## Acceptance criteria

- [x] Passes the shared engine contract kit
- [x] Full win/lose/draw matrix; best-of-N ends at the right score; draws do not count
- [x] A pending choice is never visible to the opponent or spectators — in the engine view and over real sockets
- [x] Playable end to end through the real composition root

## Verification

- 369 tests (5 consecutive green runs); `rpsEngine` 100 % lines/branches; lint 0; audit 0.
- Live run against MongoDB: best-of-3 with a draw (rock/rock), 2–1 result, and a recorder on the second player's
  socket confirmed the opponent never received a pending choice.
