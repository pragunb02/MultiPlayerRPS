## Root cause

`apps/server/src/server.js` calls `server.listen(port)` with no host, so Node binds every interface. On Render that
is required (the public web service), but a developer running `npm run dev:server` or `npm start` on a laptop also
exposes the server, its session cookie and the dev database behind it to the local network. Docker Compose already
publishes only on 127.0.0.1.

## Plan

1. Add `HOST` to config: default `127.0.0.1`, validated, documented in `.env.example` and DEPLOYMENT.md.
2. **Before merge, the owner sets `HOST=0.0.0.0` in Render** (otherwise production stops answering). The PR's
   Deployment impact lists it as an env var to set first.
3. Docker: the container sets `HOST=0.0.0.0` inside the image only, since its published port stays 127.0.0.1.
4. Tests: the default is loopback; the configured host is used; the e2e server stays on loopback.
