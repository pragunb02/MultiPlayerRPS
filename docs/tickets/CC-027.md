## Scope

`.github/workflows/ci.yml`, on every pull request and every push to `main`:

- **checks** — `npm ci`, lint, format check, `npm audit --audit-level=high`, `npm run test:coverage` (unit +
  integration on an in-memory MongoDB; gates 100 % lines/functions, 99 % branches). Coverage report kept 14 days.
- **e2e** — Chromium installed, `npm run test:e2e`: builds the web app and runs the 84 browser persona tests (desktop +
  mobile) against the real server in production config. On failure, the Playwright report and traces are kept.
- Node from `.nvmrc`; npm and MongoDB binaries cached; a newer push cancels the older run on the same branch;
  read-only token.
- Actions on their latest stable majors (checkout 7, setup-node 7, cache 6, upload-artifact 7).

## Verification

- Green on its first run: checks 1 min 01 s, browser tests 1 min 28 s.

## Follow-up

- Require both jobs before merging (GitHub → Settings → Branches → rule for `main`) — a repository setting for the
  owner.
