## Why

Server-authoritative play (ADR-000) needs every game to expose the same pure functions so rooms, matches, bots and
replays can treat games uniformly. A written contract is not enough: engines must be _proved_ to honour it.

## Scope

- In:
  - `@classicade/games` package (pure; lint-enforced: no I/O, timers, `Math.random`, `Date.now`).
  - `GameEngine` contract (JSDoc): `validateOptions`, `init({ players, options, rng })`, `validateMove(state, player, raw, { now })`,
    `applyMove`, `getOutcome` (never null: `ongoing` | `finished` with result/winners/reason), `viewFor(state, viewer)`, `activePlayers`.
  - `defineEngine()` — shape check + freeze at definition time; `createEngineRegistry()` — plug-in lookup, duplicate ids refused.
  - `ok()` / `reject()` results (rejection reasons from shared `MOVE_REJECTIONS`); `createSeededRng()` (mulberry32) for replayable randomness.
  - Contract test kit (`@classicade/games/testing`): 10 checks — options, determinism, JSON-safe state, garbage-input
    robustness, outsiders, scenario rejections, full playthrough without mutation, game-over refusal, JSON-safe views, replay.
    `describeEngineContract(engine, scenario, { describe, it })` for engine test files; `checkEngineContract()` returns violations.
  - Reference engine `race` (test-only) used to test the tooling.
- Out: real engines (RPS CC-018, TTT CC-019, Chess CC-020); room/move socket event contracts move to CC-015 where they are used.

## Acceptance criteria

- [x] Contract documented; malformed engines fail at definition
- [x] Registry lookup is the only way to reach an engine; unknown id fails loudly
- [x] Contract kit passes for a correct engine and catches each kind of broken engine (mutation, throwing on garbage,
      hidden randomness, non-JSON state, outsiders, moves after game over, wrong outcome, non-JSON views)
- [x] 100 % coverage for `packages/games`; lint purity rules apply

## Notes

- The kit's own tests caught a weakness in the kit: comparing JSON text could not detect `Date` or functions in state.
  Replaced with a structural "plain JSON data only" check.
