## Why

The server plays all three games; players need boards. Boards render only what the server sends and only send intents.

## Scope

- In:
  - **RpsBoard**: three large choices, your pending choice marked, opponent shown only as "has chosen", score, best-of,
    round history.
  - **TicTacToeBoard**: accessible 3×3 grid (`grid`/`gridcell`, cell names like "top right: empty"), your mark, turn,
    winning line.
  - **ChessBoard**: click-to-move with legal targets from client-side chess.js (hints only — the server validates);
    orientation by your colour; last move, selection and check highlights; promotion picker; move list; resign (confirmed);
    offer/accept draw; live clocks.
  - **Drift-free clocks**: room views carry `serverTime`; `useChessClocks` measures only time elapsed since the view arrived,
    so a wrong local clock never shows a wrong chess clock.
  - Shared `TurnBanner`, `useMove` (busy state + server's refusal reason); boards registered in the client registry and
    **lazy-loaded** (chess.js ships only to chess players: 13.8 KB gz chunk).
  - Chess pieces: Cburnett set (CC BY-SA 3.0) with attribution in `public/pieces/LICENSE.md`.
- Out: bots (CC-038–040), PGN export/replay viewer (CC-041), rematch (CC-037).
