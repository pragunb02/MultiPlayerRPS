## Research (written before any code)

1. **Our code today.** `styles/tokens.css` switches to the dark colours only through
   `@media (prefers-color-scheme: dark)`, and reduced motion only through `prefers-reduced-motion` (tokens, the
   `global.css` rule and `useReducedMotion()`). `index.html` has `<meta name="color-scheme" content="light dark">`
   and no `theme-color`. There is no setting for either. The vision promises "Motion: full / reduced" in settings
   (§5.12) and "a dark theme by default, with a light theme" (§5.13), which the code does not do: the OS decides.
   The CSP is `script-src 'self'` (no inline script). Web storage may hold only the keys in `STORAGE_ALLOWLIST`
   (`e2e/fixtures.js`), today just `cc.sound` (ADR-018).
2. **Others.** MDN `light-dark()` (Baseline 2024, May 2024, read 2026-10-19): one declaration per colour picks light
   or dark by the active `color-scheme`, so `[data-theme="dark"] { color-scheme: dark }` overrides the OS without a
   second list. Josh Comeau, "The quest for the perfect dark mode" (2020-04-22, updated 2026-02-23): a theme applied
   after the app starts flashes the wrong colours; the fix is to set it before the first paint with a blocking
   script. WCAG 2.3.3 (AAA): motion from interaction can be turned off. Most games and game sites (chess.com,
   lichess, general knowledge, medium confidence) offer a light and dark choice in settings and follow the OS until
   the player picks.
3. **Best for ClassiCade.** A choice of theme (System, Dark, Light) and motion (System, Reduced) in the settings
   menu, applied before the first paint through a same-origin blocking `/theme.js` in `<head>` (CSP-safe, a few
   hundred bytes) that sets `data-theme` and `data-motion` on `<html>`. Tokens move to `light-dark()` or a
   `[data-theme]` block; `useReducedMotion()` and the `global.css` rule also read `data-motion`. A `theme-color` meta
   per theme so the phone's browser bar matches. The same attribute is the hook seasonal skins (CC-205) plug into.
   Owner, 2026-10-19 (ADR-052 points 5 and 6): the default follows the phone's setting, and the choice lives in a
   new allowed localStorage key `cc.look`, read by `/theme.js`. No cookie.

## Why

Players on a dark phone at night and players on a bright screen outside both want a choice, and some want less
motion than their OS setting gives. The vision promised both settings.

## Scope

- In: the two choices, the pre-paint script, tokens that follow `data-theme`, `data-motion` in the reduced motion
  paths, `theme-color`, the storage allowlist entry, CC-155 baselines in both themes.
- Out: seasonal skins (CC-205), per-account sync of the choice, new colours.

## Acceptance criteria

- [ ] No frame paints in the wrong theme on reload (browser check on the first paint).
- [ ] "Reduced" turns off every animation and transition, the same as the OS setting.
- [ ] Every text colour keeps 4.5:1 in both themes.
- [ ] Tests cover the change; `npm run lint`, `npm run format:check`, `npm test` pass.
- [ ] `cc.look` is in `STORAGE_ALLOWLIST` with a checker that accepts only the exact shape below, and the browser
      tests still fail on any other key.
- [ ] Docs updated (BACKLOG, PROGRESS, DATA.md, the privacy page's list of what the browser keeps).

## Plan / notes

Runs after CC-281 (both edit `tokens.css`).

**Storage allowlist plan (ADR-052 point 6, amends ADR-018 point 4).**

1. Key `cc.look`, exact shape `{"theme":"system"|"dark"|"light","motion":"system"|"reduced"}`. It is a preference
   of this browser, not of the account, and holds nothing about the player or a game, like `cc.sound`.
2. It is written only when the player changes a choice. With no key, both are `"system"`.
3. `e2e/fixtures.js` `STORAGE_ALLOWLIST` gets a `cc.look` entry whose checker accepts exactly those two fields and
   values. Any other field, value or key still fails the browser tests.
4. `/theme.js` is a same-origin file loaded without `defer` before the stylesheet. It reads the key inside
   `try`/`catch` (storage can be blocked) and sets `data-theme` and `data-motion` on `<html>`; a bad or missing
   value means `system`. It never writes.
5. DATA.md and the privacy page list `cc.look` next to `cc.sound`.
