## Research (written before any code)

1. **Our code today.** Icons are drawn inside the components that use them (`MenuIcon` in `Layout.jsx`, two sound
   icons in `SoundControl.jsx`, `TabIcon` in `LeaderboardPage.jsx`, `QuestIcon` in `DailyQuests.jsx`, `ChoiceIcon`
   in `RpsBoard.jsx`), each with its own stroke and size. Others are text symbols or emoji: `✓` in quests and the
   fairness line, `×` in `DismissButton`, `🔒` and `⚠` in the RPS fairness words (MATCH_EXPERIENCE §2). ADR-012
   ruled out icon fonts and icon libraries as dependencies.
2. **Others.** Emoji and symbols are drawn by the phone's own font, so they look different on Samsung, Xiaomi and
   Pixel phones and can be missing on old Android versions (general knowledge, high confidence). Open icon sets that
   fit our licence allowlist (CC-230): Heroicons, Phosphor and Tabler (MIT). Lucide is ISC, which is not on the
   allowlist (general knowledge of the licences, high confidence; check each repository's licence file before use).
3. **Best for ClassiCade.** A small registry `art/icons/` with about 16 icons on one 24 px grid and one stroke width
   (menu, sound on and off, close, check, lock, warning, trophy, flame, star, back, share, settings, the board tabs),
   drawn by us in the arcade style (owner, ADR-052 point 9: nothing copied from another set), each with a CREDITS row. Always `aria-hidden`
   next to text, painted with tokens. No new dependency.

## Why

A consistent, crisp set on every phone, and one place to add icons for the settings and share features.

## Scope

- In: the registry, its credits rows, replacing the icons and symbols above.
- Out: game glyphs and achievement icons (already a registry), new screens.

## Acceptance criteria

- [ ] No emoji or symbol character used as an icon in `apps/web/src` (a test over the JSX).
- [ ] Every icon file has a CREDITS row; the credits test passes.
- [ ] Tests cover the change; `npm run lint`, `npm run format:check`, `npm test` pass.
- [ ] Docs updated (BACKLOG, PROGRESS, CREDITS.md).
